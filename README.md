# Titanic AI Dashboard

## Description
This is an interactive AI Dashboard built using Streamlit, Pandas, and Plotly on the Titanic dataset.

## Features
- Dataset Overview
- Data Cleaning
- Key Performance Indicators (KPIs)
- 5 Visualizations
- Interactive Filters

## Dataset
Titanic Dataset

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## How to Run

pip install streamlit pandas plotly

streamlit run app.py
